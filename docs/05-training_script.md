在每个 epoch 开始时 `np.random.shuffle(batch_offsets)`。\n- 内层循环遍历 `batch_offsets` (或其一部分，直到 `valid_index`)。\n- 调用 `get_batch` 函数获取当前批次数据。\n- 将批次数据转换为 PyTorch 张量并移至设备。\n- `optimizer.zero_grad()`。\n- `prediction = model(data_batch)`。\n- `cur_loss, cur_reg_loss, cur_rank_loss, _ = get_loss(...)`。\n- `cur_loss.backward()`。\n- `optimizer.step()`。\n- 累积和记录训练损失。\n\n**提示词 (针对 LLM)**:\n\"请描述 `train.py` NumPy 批次数据转换为 PyTorch 张量，并将它们发送到之前选择的计算设备？\n6.  **模型训练步骤**:\n    a.  清零梯度 (`optimizer.zero_grad()`)。\n    b.  通过模型进行前向传播，获取预测 (`prediction = model(data_batch)`)。\n    c.  调用 `get_loss` 函数计算当前批次的损失 (`cur_loss`, `cur_reg_loss`, `cur_rank_loss`)。\n    d.  执行反向传播 (`cur_loss.backward()`)。\n    e.  更新模型参数 (`optimizer.step()`)。\n7.  **损失记录**: 如何累积每个批次的损失值，并在每个 epoch 结束时计算平均训练损失 (`tra_loss`, - **目标**: 确保整个训练流程能够无错误地跑通，包括数据加载、模型前向/反向传播、损失计算和参数更新。\n    - **检查点**: \n        - 打印每个批次的损失值，观察损失是否是有效的数值 (不是 NaN 或 inf)。\n        - 观察损失值是否在训练过程中有轻微变化的趋势（通常是下降，但初期可能波动）。\n        - 确认模型参数在
