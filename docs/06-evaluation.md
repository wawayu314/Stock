\\\n# 步骤 6: 评估脚本和指标实现 (`evaluator.py`)\n\n本节将指导您实现用于评估模型预测性能的 `evaluator.py` 脚本。该脚本中的 `evaluate` 函数将计算多个关键的金融和统计指标。\n\n## 6.1 `evaluate` 函数的整体结构\n\n**任务**: 设计 `evaluate` 函数的输入、输出和主要计算流程。\n\n**背景信息 (`train.py` 中的调用)**:\n`cur_valid_perf = evaluate(cur_valid_pred, cur_valid_gt, cur_valid_mask)`\n- `cur_valid_pred`: 模型预测的（可能是排序相关的）值，形状 `[S, TimeWindowLength]` (S 为股票数，TimeWindowLength 是验证/测试集的时间长度)。\n- `cur_valid_gt`: 真实的收益率，形状 `[S, TimeWindowLength]`。\n- `cur_valid_mask`: 掩码，标记有效数据点，形状 `[S, TimeWindowLength]`。\n\n**输出 (`train.py` 中的打印)**:\n`\'mse:{:.2e}, IC:{:.2e}, RIC:{:.2e}, prec@10:{:.2e}, SR:{:.2e}\'`\n这表明 `evaluate` 函数返回一个包含 MSE, IC, RIC, Precision@10, Sharpe Ratio (SR) 等指标的字典。\n\n**提示词 (针对 LLM)**:\n\"我需要创建一个 `evaluator.py` 文件，其中包含一个 `evaluate` 函数，用于计算股票预测模型的性能指标。请基于以下信息描述其设计：\n- **输入参数**:\n    - `pred_data`: 模型的预测输出，一个 NumPy 数组，形状为 `[stock_num, num_days]`，代表每只股票在每天的预测值（例如，预测的收益率或排序分数）。\n    - `gt_data`: 真实的收益率数据，一个 NumPy 数组，形状为 `[stock_num, num_days]`。\n    - `mask_data`: 掩码数据，一个 NumPy 数组，形状为 `[stock_num, num_days]`，标记有效数据点 (1 表示有效, 0 表示无效)。\n- **核心逻辑**: \n    函数内部将逐天（或整体）计算以下指标，并处理掩码以排除无效数据：\n    1.  均方误差 (MSE)。\n    2.  信息系数 (IC) 和秩信息系数 (Rank IC / RIC)。\n    3.  Precision@K (例如，K=10)，表示预测收益率最高的K只股票中，实际收益率为正的比例，或实际收益率排名前K的比例。\n    4.  夏普比率 (Sharpe Ratio, SR)，衡量风险调整后的收益。\n- **返回值**: 一个字典，键是指标名称 (如 \'mse\', \'IC\', \'RIC\', \'prec_10\', \'sharpe5\')，值是对应的计算结果。\n\n请概述这个 `evaluate` 函数的结构，以及它如何组织对各个具体指标计算函数的调用。不要提供 Python 代码。\"\n\n**测试方法**:\n- **整体结构审查**: 检查函数签名是否正确，是否准备处理所有必需的指标。\n\n## 6.2 均方误差 (MSE)\n\n**任务**: 实现带掩码的均方误差计算。\n\n**提示词 (针对 LLM)**:\n\"在 `evaluate` 函数中，我需要计算预测值 (`pred_data`) 和真实值 (`gt_data`) 之间的均方误差 (MSE)，同时考虑 `mask_data`。\n- **输入**: `pred_data` (`[S, D]`), `gt_data` (`[S, D]`), `mask_data` (`[S, D]`) (S: 股票数, D: 天数)。\n- **计算**: \n    1. 计算差的平方: `(pred_data - gt_data)^2`。\n    2. 乘以掩码: `diff_squared * mask_data`。\n    3. 计算所有有效数据点的平均值: `sum(diff_squared * mask_data) / sum(mask_data)`。\n\n请确认此计算方法，并指出这是否与损失函数中计算的回归损失部分（如果 MSE 是回归损失）在逻辑上相似。\"\n\n**测试方法**:\n- **单元测试** (准备创建 `test_evaluator.py` 文件):\n    - **测试用例**: 使用小型的、已知的 `pred_data`, `gt_data`, `mask_data` NumPy 数组。\n        - **全掩码**: `mask_data` 全为1。结果应与不带掩码的 MSE 计算一致。\n        - **部分掩码**: `mask_data` 部分为0。手动计算仅考虑有效数据的 MSE，并与函数输出比较。\n        - **零掩码**: `mask_data` 全为0。结果应为0或NaN（取决于实现，需明确）。\n\n## 6.3 信息系数 (IC) 和秩信息系数 (Rank IC)\n\n**任务**: 实现 IC 和 Rank IC 的计算。IC衡量预测值与实际值之间的线性相关性，Rank IC衡量预测值的排序与实际值的排序之间的相关性 (通常使用 Spearman 等级相关系数)。\n\n**提示词 (针对 LLM)**:\n\"我需要在 `evaluate` 函数中计算信息系数 (IC) 和秩信息系数 (Rank IC)。\n- **IC (Pearson Correlation)**:\n    - **输入**: `pred_data` (`[S, D]`), `gt_data` (`[S, D]`), `mask_data` (`[S, D]`)。\n    - **计算思路**: 通常逐日计算。对于每一天 `d`：\n        1.  获取当天的有效预测 `p_d = pred_data[:, d][mask_data[:, d] == 1]`。\n        2.  获取当天的有效真实收益 `g_d = gt_data[:, d][mask_data[:, d] == 1]`。\n        3.  如果有效数据点足够多，计算 `p_d` 和 `g_d` 之间的皮尔逊相关系数。\n        4.  所有每日 IC 值的平均值即为最终的 IC。\n- **Rank IC (Spearman Correlation)**:\n    - **输入**: 同上。\n    - **计算思路**: 通常也逐日计算。对于每一天 `d`：\n        1.  获取当天的有效预测 `p_d` 和有效真实收益 `g_d` (同IC)。\n        2.  如果有效数据点足够多，计算 `p_d` 的秩和 `g_d` 的秩。\n        3.  计算这两个秩序列之间的皮尔逊相关系数 (即 Spearman 等级相关系数)。\n        4.  所有每日 Rank IC 值的平均值即为最终的 Rank IC。\n\n请描述在 NumPy/SciPy 环境下计算这些相关系数的常用方法，以及如何正确处理掩码和每日计算并最终聚合。指出需要注意的边界情况 (例如某天有效数据过少)。\"\n\n**测试方法** (在 `test_evaluator.py` 中):\n- **IC 测试用例**: \n    - **完美正相关/负相关/不相关**: 创建 `pred_data` 和 `gt_data`，使其逐日表现出完美的正相关、负相关或不相关 (例如 `pred_data[:, d] = gt_data[:, d]`, `pred_data[:, d] = -gt_data[:, d]`, `pred_data[:, d]` 为随机值与 `gt_data[:, d]` 无关)。验证计算出的 IC 是否接近 1, -1, 0。\n    - **掩码影响**: 使用部分掩码，确保只有有效数据参与计算。\n- **Rank IC 测试用例**: \n    - **完美正序/逆序/乱序**: 创建 `pred_data` 和 `gt_data`，使其逐日的排序表现出完美一致、完全相反或随机。验证计算出的 Rank IC 是否接近 1, -1, 0。\n    - **掩码影响**: 同上。\n- **数据不足处理**: 测试当某天有效数据点过少时（例如少于2个），IC/Rank IC 如何处理（例如返回 NaN 或0，并确保这不会破坏整体平均）。\n\n## 6.4 Precision@K (例如, K=10)\n\n**任务**: 实现 Precision@K 指标。例如，Precision@10 衡量模型预测的收益率最高的10只股票中，有多少 tatsächlich 表现良好 (例如，实际收益率为正，或者实际收益率也排在前列)。\n\n**提示词 (针对 LLM)**:\n\"我需要在 `evaluate` 函数中计算 Precision@K (例如，K=10)。\n- **输入**: `pred_data` (`[S, D]`), `gt_data` (`[S, D]`), `mask_data` (`[S, D]`), `K` (例如 10)。\n- **计算思路 (基于预测收益率最高的K只)**: 通常逐日计算。对于每一天 `d`：\n    1.  获取当天的有效预测 `p_d = pred_data[:, d][mask_data[:, d] == 1]` 和对应股票的真实收益 `g_d = gt_data[:, d][mask_data[:, d] == 1]`。\n    2.  如果有效股票数少于 K，则跳过当天或特殊处理。\n    3.  根据 `p_d` 对股票进行降序排序，选择预测收益率最高的 K 只股票。\n    4.  在这 K 只股票中，统计实际收益率 `g_d` 大于某个阈值 (例如 0，表示盈利) 的股票数量 `num_correct`。\n    5.  当天的 Precision@K = `num_correct / K`。\n    6.  所有每日 Precision@K 值的平均值即为最终的 Precision@K。\n\n另一种定义可能是看预测排名前 K 的股票，在真实收益率排名中是否也处于前 M 位。请澄清原始项目中 \"prec@10\" 更可能指哪种定义，并描述其计算步骤。\"\n\n**测试方法** (在 `test_evaluator.py` 中):\n- **测试用例**: \n    - **完美预测**: 设计一天的数据，使得预测收益率最高的 K 只股票的实际收益率也都是正的 (或最高的)。Precision@K 应为 1。\n    - **糟糕预测**: 预测收益率最高的 K 只股票的实际收益率都是负的 (或最低的)。Precision@K 应为 0。\n    - **部分正确**: 混合情况。手动计算预期值并比较。\n    - **掩码影响**: 确保掩码正确应用于选择股票和计算收益。\n    - **有效股票数少于 K**: 测试当某天有效股票数不足 K 时的行为 (例如，跳过计算，或按比例调整)。\n\n## 6.5 夏普比率 (Sharpe Ratio)\n\n**任务**: 实现夏普比率的计算。夏普比率衡量每单位风险所获得的超额回报。通常计算的是投资组合策略的夏普比率。对于逐只股票的预测，可能需要先构建一个基于预测的每日投资组合。\n\n**提示词 (针对 LLM)**:\n\"我需要在 `evaluate` 函数中计算夏普比率 (SR)。原始的 `train.py` 打印的是 \'SR\', 有时也可能是 \'sharpe5\'，这可能暗示基于每日top 5预测构建的投资组合的夏普比率。\n- **输入**: `pred_data` (`[S, D]`), `gt_data` (`[S, D]`), `mask_data` (`[S, D]`)。可能还有一个参数 `top_k` (例如 5)。\n- **计算思路 (基于每日 top-K 策略)**: \n    1.  对于每一天 `d`：\n        a.  获取当天的有效预测 `p_d` 和真实收益 `g_d`。\n        b.  根据 `p_d` 选出预测收益率最高的 `top_k` 只股票 (如果有效股票数不足 `top_k`，则全选或特殊处理)。\n        c.  计算这 `top_k` 只股票当日的平均实际收益率 (等权重投资组合收益) `daily_portfolio_return_d`。\n    2.  得到一个每日投资组合收益率的时间序列 `portfolio_returns = [daily_portfolio_return_d1, d2, ...]`。\n    3.  计算该收益率序列的夏普比率: `SR = mean(portfolio_returns) / std(portfolio_returns) * sqrt(annualization_factor)`。无风险利率通常假定为0。`annualization_factor` 取决于数据频率 (例如，日数据通常是252)。\n\n请描述这个计算过程，特别是如何构建每日投资组合收益率序列，以及如何计算最终的夏普比率。指出年化因子的选择。\"\n\n**测试方法** (在 `test_evaluator.py` 中):\n- **测试用例**: \n    - **持续盈利**: 设计数据，使得每日 top-K 策略总是产生正收益且波动很小。SR 应该较高。\n    - **高波动/亏损**: 设计数据，使得策略收益波动大或持续亏损。SR 应该较低或为负。\n    - **零波动（非零收益）**: 如果收益无波动但为正，标准差为0，SR可能为inf。需要明确如何处理这种情况（例如，添加一个极小的epsilon到分母）。\n    - **掩码和股票数不足 top_k**: 测试这些情况如何影响每日组合的构建和最终SR。\n\n## 6.6 组装 `evaluate` 函数\n\n**任务**: 将所有单独的指标计算函数组装到 `evaluate` 函数中，并返回包含所有结果的字典。\n\n**提示词 (针对 LLM)**:\n\"在 `evaluator.py` 中，我已经分别定义了计算 MSE, IC, Rank IC, Precision@K, Sharpe Ratio 的辅助函数。现在，请描述 `evaluate` 函数如何调用这些辅助函数，并将结果组织到一个字典中返回。\n例如：\n`perf = {}`\n`perf[\'mse\'] = calculate_mse(...)`\n`perf[\'IC\'] = calculate_ic(...)`\n`perf[\'RIC\'] = calculate_rank_ic(...)`\n`perf[\'prec_10\'] = calculate_precision_at_k(..., K=10)`\n`perf[\'sharpe5\'] = calculate_sharpe_ratio(..., top_k=5)`\n`return perf`\n\n确认这个结构是否合理。\"\n\n**测试方法**:\n- **集成测试** (在 `test_evaluator.py` 中，测试 `evaluate` 函数本身):\n    -
